# חיבור עוזר AI ליום של אורן (Claude / ChatGPT)

> **שימו לב:** חיבור שולח את נתוני המשחק של אורן (מה שיחק, תשובות, זמנים) לחברה שמפעילה את ה-AI (Anthropic או OpenAI). אלה נתונים של ילד. חברו רק אם אתם בסדר עם זה, ואל תשתפו את הקוד הסודי.

## הכנה (פעם אחת)
1. ממציאים קוד סודי ארוך (לפחות 32 תווים, אותיות ומספרים).
2. שומרים אותו ב-Cloudflare: Pages → oren-game → Settings → Variables and Secrets → `MCP_TOKEN` (Secret), ופורסים מחדש.
3. הכתובת: `https://oren-game.pages.dev/api/mcp`
4. **לבטל גישה:** מחליפים את `MCP_TOKEN` בקוד חדש ופורסים מחדש. הקוד הישן מפסיק לעבוד מיד. מוחקים את `MCP_TOKEN` = השרת כבוי.

## חיבור ל-Claude
1. claude.ai → Settings → Connectors → Add custom connector.
2. כתובת: הכתובת למעלה. בהגדרות מתקדמות מוסיפים כותרת `Authorization` עם הערך `Bearer <הקוד>`. (בשורת הפקודה: `claude mcp add --transport http oren https://oren-game.pages.dev/api/mcp --header "Authorization: Bearer <הקוד>"`.)

## חיבור ל-ChatGPT
1. Settings → Connectors → Advanced → Developer mode → Create (MCP server).
2. כתובת: הכתובת למעלה, אימות: header בשם `Authorization` עם `Bearer <הקוד>`.

## מה ה-AI יכול
- **קריאה:** סיכום יום, יומן משחק, התקדמות. אין גישה לסיסמת ההורים או לקודים.
- **כתיבה (בדיוק מה שלוח ההורים כבר יודע):** הודעה, תזכורת (מים, שירותים, לאכול), שינוי תוכנית היום, עצירה להיום וחזרה. אין מחיקה.
- כל כתיבה נרשמת ומוצגת בלוח ההורים: לשונית ⏰ תזכורת, "מה נשלח או שונה על ידי עוזר AI".
- הגבלות: 60 קריאות בדקה ו-60 כתיבות בשעה.

## שאלה מוכנה: "ננתח את היום"
> נתח את היום של אורן (בן 6-7). קרא get_day_summary ו-get_play_log ו-get_progress. ענה בעברית: כמה זמן שיחק, מה הלך טוב, איפה טעה או נתקע, מה כדאי לחזק מחר, ושלוש הצעות קצרות להורה. אל תשנה כלום ואל תשלח הודעות בלי שאבקש.
