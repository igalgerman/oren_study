# הַמַּסָּע שֶׁל אוֹרֶן — מסמך מצב והמשך עבודה

עודכן: 25.11.2026. ענף העבודה: `ccr-4b00e91b-b07vyx`.

## 1. מה באוויר עכשיו (oren-game.pages.dev)
- **כניסה:** כפתורי "אורן" ו"הורה" (סיסמת הורה). שמירה **אחת לכל המשפחה** ב-Cloudflare KV (מזהה קבוע), בלי קודים.
- **בית:** "מה בא לך היום?" (3 כרטיסים + "משהו אחר"), מסלול יומי, 🤝 זמן ביחד, משימות מהעולם האמיתי, סוף סיפור יומי, סיור של 3 שלבים (פעם אחת), חבר עוזר אחד (חיית הסטודיו).
- **חשבון:** 8 עולמות. שיעורים **אינטראקטיביים** עם מקלות של 10 וקוביות של 1. מסך עולם עם כפתור "ממשיכים" אחד ושביל מימין לשמאל.
- **עיר הכשרונות:** 12 בניינים. **ארקייד** בלי כרטיסים ופרסים.
- **בריאות:** הפסקה כל 20 דקות (מים, שירותים, תנועה, עיניים), עצירה לארוחות, החלפת נושא אחרי 15 דקות או 4 פעילויות, הגבלת זמן או מספר משימות **מהטלפון של ההורה** (מתעדכן תוך כ-20 שניות), מונה "נשאר" בסרגל.
- **קול:**
  - עברית: Google **he-IL-Chirp3-HD-Kore** במהירות 0.9.
  - אנגלית: **en-US-Chirp3-HD-Despina** במהירות 0.85.
  - **הקראה אוטומטית**. מעבר לקול הדפדפן אם Google לא עונה תוך 3 שניות. יומן תקלות בלוח ההורים.
- **הגייה:**
  - מילון תיקונים בשרת (למשל "אחדות" נשלח ל-Google ככתיב "אחאדות").
  - מספרים מומרים למילים, בזכר ובנקבה לפי המילה שאחריהם.
  - אימוג'ים מוסרים לפני ההקראה.
  - גרסת קול (`&k=`) בכתובות ההקלטות, כך שתיקון מגיע לכל המכשירים.
- **בלי אינטרנט:** service worker שומר את הדף ואת ההקלטות. כפתור "הורדת כל הקולות" בלוח ההורים.
- **לוח הורים:** סיכום, "היום של אורן" (מקוצר), הגדרות, חלקים והדרגה, מצב "לשחק כהורה" (זוכר התקדמות).

## 6. עבודה מקומית
```bash
git clone https://github.com/igalgerman/a.git
cd a && git checkout ccr-4b00e91b-b07vyx
cd oren2
python3 build_talents.py          # בונה index.html ו-cf/public/index.html
# לפתוח בדפדפן: oren2/index.html (בלי קול Google — הוא עובד רק מהאתר)
npm i -D playwright && npx playwright install chromium   # פעם אחת, לבדיקות
tests/run.sh                      # כל הבדיקות (JOBS=4 tests/run.sh אם המחשב חלש)
```
**העלאה לאתר** (צריך API token של Cloudflare עם הרשאות Pages:Edit ו-Workers KV:Edit):
```bash
export CLOUDFLARE_API_TOKEN=...   # מה-dashboard של Cloudflare. לא לשמור בגיט!
bash cf/tools/deploy.sh
node cf/tools/pregen.js           # הכנת קולות למשפטים חדשים
node cf/tools/voicecheck.js       # בדיקת הגייה (משתמש ב-GEMINI_KEY שבשרת)
```
**מפתחות** (נשמרים רק ב-Cloudflare, Settings ← Variables and Secrets):
- `GOOGLE_TTS_KEY`: הקול
- `GEMINI_KEY`: בדיקת ההגייה
- KV binding: `SAVES`
